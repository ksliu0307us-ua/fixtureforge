# Synthetic examples

The inventory and build-artifact schemas describe invented data. Their `.sample.json`
and `.sample.csv` files were generated by FixtureForge 0.1.0 with five rows and seed
`42`.

Regenerate to new paths (existing samples are intentionally protected):

```bash
fixtureforge generate examples/inventory.schema.json --rows 5 --seed 42 --format json --output output/inventory.json
fixtureforge generate examples/build-artifacts.schema.json --rows 5 --seed 42 --format csv --output output/artifacts.csv
```
