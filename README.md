# FixtureForge

FixtureForge is an offline Python command-line tool that generates deterministic
synthetic JSON and CSV fixtures for ordinary application tests and demonstrations.
It is a new, original, AI-assisted implementation with no third-party runtime
dependencies. All bundled products, inventory items, and build artifacts are
invented. The project is MIT licensed.

## Install

Python 3.11 or later is required:

```bash
python -m venv .venv
```

```powershell
.venv\Scripts\Activate.ps1
python -m pip install .
```

On macOS/Linux, activate with `source .venv/bin/activate`. The installed
`fixtureforge` command and `python -m fixtureforge` are equivalent.

## Commands

```bash
fixtureforge validate examples/inventory.schema.json
fixtureforge validate examples/inventory.schema.json --format json
fixtureforge describe examples/inventory.schema.json
fixtureforge describe examples/inventory.schema.json --format json
fixtureforge preview examples/inventory.schema.json --rows 5 --seed 42 --format json
fixtureforge preview examples/inventory.schema.json --rows 5 --seed 42 --format csv
fixtureforge generate examples/inventory.schema.json --rows 100 --seed 42 --format json --output output/inventory.json
fixtureforge generate examples/inventory.schema.json --rows 100 --seed 42 --format csv --output output/inventory.csv
```

`validate` reports all discoverable schema problems and exits `1` for an invalid
schema. `describe` lists the version, ordered fields, types, and options. `preview`
writes only fixture data to stdout and keeps diagnostics on stderr. `generate`
exclusively creates the requested file, refuses overwrites, and removes an
incomplete file if its own write fails. Preview and generation require an explicit
integer seed and nonnegative row count.

## Schema

Schemas are versioned JSON objects with a nonempty ordered `fields` list. Field
names match `[A-Za-z_][A-Za-z0-9_]*`.

```json
{
  "schema_version": 1,
  "fields": [
    {"name": "item_id", "type": "sequence", "start": 1000, "step": 1},
    {"name": "category", "type": "choice", "values": ["bolt", "nut"]},
    {"name": "quantity", "type": "integer", "min": 0, "max": 500},
    {"name": "active", "type": "boolean"},
    {"name": "received_on", "type": "date", "start": "2026-01-01", "end": "2026-12-31"}
  ]
}
```

- `sequence`: integer `start` and positive integer `step`.
- `integer`: inclusive integer `min` and `max`.
- `choice`: nonempty `values` array containing strings.
- `boolean`: no options; emits JSON booleans and CSV `true`/`false`.
- `date`: inclusive real calendar dates in canonical `YYYY-MM-DD` form.

Validation rejects unsupported versions, duplicate JSON keys or field names,
unknown fields/types/options, invalid names, missing or incorrectly typed options,
booleans used as integers, reversed ranges, invalid dates, and empty choices. The
entire schema and command arguments are validated before output is created.

## Reproducibility and output

Each run owns one local `random.Random(seed)` and generates records incrementally in
schema field order. FixtureForge never modifies global random state. With
FixtureForge 0.1.0 on the same tested Python minor version, identical schema bytes,
seed, row count, and format produce identical output. Compatibility across future
FixtureForge releases or untested Python versions is not promised.

A five-row run is the prefix of a longer run using the same schema and seed. JSON
objects and CSV columns preserve schema order. UTF-8, Unicode, commas, quotes, and
line breaks are handled correctly; generated files use LF line endings. Output has
no timestamps or environmental values. Zero rows produce `[]` for JSON or a CSV
header only.

## Exit codes

| Code | Meaning |
| ---: | --- |
| `0` | Successful validation, description, preview, or generation. |
| `1` | Schema validation failed. |
| `2` | Invalid arguments, output conflict, or operational failure. |

Expected errors are concise and omit tracebacks.

## Tests

```bash
python -m unittest discover -s tests -v
```

The synthetic suite covers every type and boundary, strict schema errors, seeded
reproducibility, prefix consistency, global random isolation, ordering, zero rows,
Unicode/CSV quoting, output conflicts, failed-write cleanup, and CLI exit codes.

## Limitations

Version 0.1.0 has no cross-dataset relationships, uniqueness or nullability rules,
dependent templates, JSONL/SQL exports, or schema migration. These are proposed and
unimplemented; see [ROADMAP.md](ROADMAP.md). FixtureForge produces conventional
synthetic test data and is not intended for sensitive or production-data synthesis.
